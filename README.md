# 暗記のアニキ 素材集

**[「暗記のアニキ」](https://ankiniki2026.web.app/)**はユーザーの学習目標日に合わせた**自動復習スケジューリング**、**OCR（画像文字認識）による単語カード生成**、**オンライン共有機能**などを備えたオールインワン暗記学習アプリです。
本リポジトリでは、暗記のアニキで使用している画像等の素材を配布しています。
